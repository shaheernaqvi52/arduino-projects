# Arduino Projects

I'm an Electrical Engineering student at NUST (National University of Sciences and Technology), Class of 2030. Before starting university, I taught myself the basics of Arduino and electronics through hands-on tinkering. This repo collects a few of the small projects I built along the way, nothing polished or "big", but each one taught me something new about circuits, coding logic, and debugging.

I'm especially interested in Telecommunications, RF, and Microwave Engineering, and I'm looking forward to building on these fundamentals.

## Projects

### 🖩 [LCD Calculator](./Cal)
A simple calculator built using an Arduino and LCD display takes input, performs calculations, and prints results to the screen in real time.

### 💡 [LED Brightness Control with Potentiometer](./LedBrightnessPotentiometer)
A circuit where a potentiometer controls LED brightness in real time, converting analog input into a variable PWM output signal.

### 🎨 [Color-Sensing RGB LED](./ColourSensingRGB-LED)
Reads the RGB composition of an object's reflected light using pulse-width sensing, determines the dominant color, and drives an RGB LED to match it in real time.

### 🌡️ [Temperature & Humidity Monitor (DHT11)](./Temp&HumidSensor)
Reads live temperature and humidity data from a DHT11 sensor and outputs it via serial monitor.

### ⚙️ [Servo Motor Control via Potentiometer](./ServoControlWithPotentiometer)
Controls a servo motor's position in real time using a potentiometer, translating analog readings into precise motor angle output.

## What I learned
Working through these projects gave me a practical foundation in:
- Reading and interpreting analog and digital sensor data
- Writing control logic in C++ for embedded systems
- Debugging circuits and code through trial and error
- Basic PWM, signal timing, and actuator control
